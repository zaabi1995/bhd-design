# Product

## Register

product

## Users

BHD Group designers, developers, operators, and AI-assisted delivery teams building public sites, admin tools, documents, and internal systems across the group portfolio. They need trusted reusable elements that work in English and Arabic without rebuilding foundations for every project.

## Product Purpose

design.bhd.om is the shared BHD Group design runtime and reference library. It provides production-ready tokens, components, interaction patterns, icons, RTL utilities, currency formatting, and starter shells. Success means a team can find an approved element, copy or load it, and ship a consistent BHD interface quickly.

## Brand Personality

Precise, practical, confident. The interface should feel like an internal professional tool: direct enough for daily work, polished enough to demonstrate the standards it documents.

## Anti-references

- Decorative design galleries that hide implementation details.
- Generic startup styling, purple gradients, excessive glass, and oversized marketing headlines.
- Dense icon walls without search, source labels, keyboard support, or clear usage rights.
- English-only layouts or components that break under RTL.
- Emoji used as interface icons.

## Design Principles

1. Practice what the system documents.
2. Make every asset immediately usable through copy, download, or stable URLs.
3. Keep provenance and usage rights visible at the point of selection.
4. Treat RTL, keyboard access, reduced motion, and dark mode as defaults.
5. Prefer a fast searchable tool over a decorative showcase.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support keyboard-only use, visible focus states, semantic labels, reduced motion, high contrast in light and dark themes, and complete English and Arabic layout compatibility. Icons must include accessible names when they convey meaning and remain hidden from assistive technology when decorative.
